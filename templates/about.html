🧠 About the Project

AI Data Classification

A machine learning web application that uses a Decision Tree algorithm to classify Iris flowers based on their physical measurements.

PROJECT OVERVIEW

How the System Works

The application connects a trained machine learning model with a simple interactive web interface.

01
📊

Input Data

The user enters four measurements: sepal length, sepal width, petal length and petal width.

02
🧠

Decision Tree

The trained Decision Tree analyzes the measurements and identifies patterns.

03
🔮

Prediction

The model predicts whether the flower belongs to Setosa, Versicolor or Virginica.

04
📈

Result

The prediction and model confidence are displayed instantly on the website.

🌳 ALGORITHM

Decision Tree

A Decision Tree is a supervised machine learning algorithm that makes predictions by splitting data according to feature values.

In this project, the algorithm learns from Iris flower measurements and creates a tree structure for classifying new observations.
