# AI Data Classification Using Decision Tree

## Project Description

This project demonstrates a basic Artificial Intelligence classification model using Python and Scikit-learn.

The program loads the Iris dataset, splits the data into training and testing sets, trains a Decision Tree classifier, predicts flower classes, and calculates the model accuracy.

---

## Features

- Load Iris Dataset
- Train Decision Tree Model
- Test the Model
- Predict New Data
- Display Accuracy

---

## Technologies Used

- Python
- Scikit-learn
- NumPy
- Pandas

---

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python classification.py
```
